# Условия установки PIXIE

Перед продолжением ознакомьтесь с условиями использования и составом демонстрационного пакета.

> Этот установщик показывает интерфейс и работу компонентов FMXPixie. В демонстрационном режиме файлы программы не копируются на компьютер.

## Что входит в пакет

PIXIE объединяет несколько готовых материалов для работы с интерфейсом:

- **Основные файлы** — базовые компоненты и необходимые ресурсы.
- **Примеры интерфейсов** — готовые страницы и варианты оформления.
- **Графические материалы** — иллюстрации, значки и SVG-изображения.
- **Дополнительные темы** — альтернативные цветовые схемы.

## Перед установкой

Убедитесь, что выбранная папка доступна для записи. Для обычной установки достаточно нескольких свободных мегабайт.

| Параметр | Рекомендация |
| --- | --- |
| Операционная система | Windows 10 или Windows 11 |
| Архитектура | Соответствует разрядности приложения |
| Папка установки | Любая доступная папка |
| Дополнительные модули | Выбираются на следующем шаге |

## Как проходит установка

1. Выберите папку и язык интерфейса.
2. Отметьте необходимые компоненты.
3. Проверьте итоговый список.
4. Подтвердите параметры.

На каждом шаге можно вернуться назад и изменить выбор.

## Важные замечания

**Настройки можно изменить до подтверждения.** После перехода к итоговой странице установщик покажет выбранные параметры.

Названия компонентов и иллюстрации в этом примере являются демонстрационными. Они не означают, что реальные файлы будут установлены.

Для получения информации о проекте откройте [страницу FMXPixie на GitHub](https://github.com/audiofeel/FMXPixie).

### Пример пути установки

Обычно приложение размещают в отдельной папке:

`C:\Program Files\PIXIE`

Выберите удобное расположение и нажмите **«Далее»**, чтобы продолжить.
